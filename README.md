# 🛠️ My First Terminal Tool

> *"It's not much, but it's honest work"*

## 📖 About

This is my very first terminal tool! A simple Python script that searches for text patterns in files. 

**Warning:** This tool has a lot of problems (I know, I'm learning! 😅). Use with patience and a sense of humor.

## ✨ Features

- 🔍 Search for the **first** occurrence of a pattern in a file
- 📄 Display the matching line with line number
- 🆘 Built-in help menu
- 🎯 Case-insensitive search (because I'm nice like that)
